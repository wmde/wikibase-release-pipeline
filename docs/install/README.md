# Installation

You can install WBS using two methods:

1. [Via the Installer](./installer.md):
This method is recommended for those new to this stack or prefer using a web-based installer. It requires minimal technical expertise and guides you through the entire process.

2. [Via the CLI](./install-via-cli.md):
This method will allow you to install the WBS stack using the CLI. This requires you to have some technical knowledge and comfort with using the terminal. 

If you face any issues during installation, you can take a look at our page for [Troubleshooting](../operate/troubleshooting.md). If you have questions or need help, use this [bug report form](https://phabricator.wikimedia.org/maniphest/task/edit/form/129/) to start a conversation with the engineering team.


# Uninstalling WBS

You can easily uninstall WBS by following our [guide](./uninstall.md).
