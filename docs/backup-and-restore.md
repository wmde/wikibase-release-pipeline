# Backup and restore

Besides [your configuration](./advanced-configuration.md), your data is what makes your instance unique. Wikibase Suite stores service data in [Docker volumes](https://docs.docker.com/storage/volumes/).

- `wikibase-image-data`: MediaWiki image and media file uploads
- `mysql-data`: MediaWiki/Wikibase MariaDB raw database
- `wdqs-data`: query service raw database
- `elasticsearch-data`: OpenSearch raw database
- `quickstatements-data`: QuickStatements data and generated OAuth binding for this MediaWiki instance
- `traefik-letsencrypt-data`: Traefik SSL certificates generated by Let's Encrypt

## Back up your data

1. Change to the Wikibase Suite directory for the installed version.

   For WBS 7 and earlier:

   ```sh
   cd /path/to/wikibase-release-pipeline/deploy
   ```

   For WBS 8 and later:

   ```sh
   cd /path/to/wikibase-suite
   ```

2. Create a `backup` directory beside that directory, shut down the instance, and dump the contents of all Docker volumes into `.tar.gz` files there.

   ```sh
   mkdir -p ../backup
   docker compose down

   for v in \
       wbs-deploy_wikibase-image-data \
       wbs-deploy_mysql-data \
       wbs-deploy_wdqs-data \
       wbs-deploy_elasticsearch-data \
       wbs-deploy_quickstatements-data \
       wbs-deploy_traefik-letsencrypt-data \
       ; do
     docker run --rm --volume $v:/backup debian:12-slim tar cz backup > ../backup/$v.tar.gz
   done
   ```

## Back up your configuration

1. Change to the Wikibase Suite directory for the installed version.

   For WBS 7 and earlier:

   ```sh
   cd /path/to/wikibase-release-pipeline/deploy
   ```

   For WBS 8 and later:

   ```sh
   cd /path/to/wikibase-suite
   ```

2. Copy the `config` directory and `.env` file into the same backup directory.

   ```sh
   mkdir -p ../backup/config
   cp -a ./config/. ../backup/config/
   cp -a ./.env ../backup/.env
   ```

Keep this backup as a reference when resetting or upgrading. The `.env` file and configuration may contain plaintext passwords and other secrets, so store the backup directory securely. Do not restore old generated configuration files wholesale after reset; manually re-apply your local changes into the new files created during reset.

## Restore from a backup

1. Change to the Wikibase Suite directory for the installed version.

   For WBS 7 and earlier:

   ```sh
   cd /path/to/wikibase-release-pipeline/deploy
   ```

   For WBS 8 and later:

   ```sh
   cd /path/to/wikibase-suite
   ```

2. Shut down the instance and populate the Docker volumes with data from the sibling `backup` directory. Only restore these backups when recovering from a failed upgrade or reset.

   Warning: the restore commands remove the existing Docker volumes before restoring the backup files.

   ```sh
   docker compose down

   for v in \
       wbs-deploy_wikibase-image-data \
       wbs-deploy_mysql-data \
       wbs-deploy_wdqs-data \
       wbs-deploy_elasticsearch-data \
       wbs-deploy_quickstatements-data \
       wbs-deploy_traefik-letsencrypt-data \
       ; do
     docker volume rm $v 2> /dev/null
     docker volume create $v
     docker run -i --rm --volume $v:/backup debian:12-slim tar xz < ../backup/$v.tar.gz
   done
   ```
